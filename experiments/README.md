# Experiment registry (source of truth)

Machine-readable history for Safe RL / VERL-agent experiments on aicenteritl.

- `registry.yaml` — experiments
- `hypotheses.yaml` — active research hypotheses
- `meta.yaml` — project goal, baselines, compare presets, rules
- `snapshots/` — launch reproducibility dumps
- `metrics_cache/` — cached metric scrapes
- `runtime/` — dashboard PID / running process pointer

UI: `../experiment_dashboard/`

Do not keep experiment history only in chat.
